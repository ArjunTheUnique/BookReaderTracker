Findings the Builder surfaced (credit where due)
F1. pdfx is a Flutter plugin and cannot run inside flutter test — proved empirically. M2 hides extraction behind an injectable PageExtractor port, which is the only reason the suite can run at all.
F2. Dart is nominally typed, so M1 doesn't automatically satisfy M2's LibraryStorePort; a one-line adapter wraps it. Recommended: declare the port in shared/contracts.dart at M1's next bump.
F3. A real M1 defect: a repeated idempotency key whose payload carries a different book_id returns E4 instead of the original success. M2 works around it by deriving a stable book_id from the key — but M1 should be fixed. Fix order issued.
F4. Sandbox memory (2 GB) can OOM a build_runner re-run; a clean build succeeds. Environmental, not a code defect.
