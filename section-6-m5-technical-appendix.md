# SECTION 6 — MODULE TECHNICAL APPENDIX

| Technical Term / Syntax Used | Plain-English Definition | 1-Sentence Everyday Analogy |
|---|---|---|
| App-group / shared store | A small storage area both the app and its widget can read. | A shared noticeboard both the office and the shopfront can see. |
| Control switch (C6) | A decision or rule — a yes/no that changes what happens. | The light switch: it decides, it does not carry the electricity. |
| Data pipe (D5) | The plumbing that carries the payload, doing no deciding. | The pipes that carry water once the tap is turned. |
| Deep link | A tap that opens the app straight to a specific item. | A bookmark that opens the book exactly at your page. |
| Dependency injection | Handing a component the helpers it needs rather than letting it build them. | Being given the tools instead of rummaging in a locked cupboard. |
| Error shape (E1–E9) | The one agreed object every failure is reported in. | A standard incident form, the same fields every time. |
| home_widget | A Flutter plugin that writes to the OS widget store. | The sign-writer who paints the number on the shopfront. |
| ISO-8601 timestamp | A date-and-time written in one standard machine-readable form. | Writing the date as 2026-10-19 so no one argues about day/month order. |
| Permission denied (E8) | The OS refused the widget permission. | Being told you may not put a sign on the shopfront. |
| Port (injected interface) | A named doorway through which a platform capability is reached. | A service hatch in a wall — you pass things through it. |
| Push (widget) | Sending fresh numbers to the widget. | Refreshing the number on the shopfront board. |
| Staleness guard | Making a widget show "—" rather than old numbers when data is out of date. | A clock that shows "--:--" until it can set itself. |
| Tap route | Turning a widget tap into a link the app can open. | A doorbell that tells you exactly which room to go to. |
| Widget payload | The small bundle of numbers the widget displays. | The one-line summary pinned to the board. |
| WidgetHost port | The injectable boundary behind which the widget plugin lives. | A hatch through which you hand the sign to the sign-writer. |
