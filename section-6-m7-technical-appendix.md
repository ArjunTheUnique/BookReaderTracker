# SECTION 6 — MODULE TECHNICAL APPENDIX

| Technical Term / Syntax Used | Plain-English Definition | 1-Sentence Everyday Analogy |
|---|---|---|
| Clock port (injected) | A replaceable "what time is it" source, so time is controllable in tests. | A wall clock you can wind forward by hand during a rehearsal. |
| Control switch (C1) | A decision or rule — the home view reflects the seeded tiles. | The light switch: it decides, it does not carry the electricity. |
| Data pipe (D7) | The plumbing that composes each tile, doing no deciding. | The pipes that carry water once the tap is turned. |
| Dependency injection | Handing a component the helpers it needs rather than letting it build them. | Being given the tools instead of rummaging in a locked cupboard. |
| Empty catalog | A fresh library with no books — a valid 6 empty tiles, not a failure. | A tidy shelf with six empty slots: nothing to show, nothing broken. |
| Error shape (E1–E9) | The one agreed object every failure is reported in. | A standard incident form, the same fields every time. |
| Import prefix (`as grid`) | Naming an import so two same-named things can live in one file. | Two colleagues called Sam, so you say "Sam from accounts". |
| Nominally typed (Dart) | A class only satisfies an interface if it explicitly says it implements it. | A club that only lets you in if your name is on the list. |
| No-scroll grid | The 6x6 shape that always fits the screen without scrolling. | A tray with exactly six wells, so nothing ever spills onto the floor. |
| Port (injected interface) | A named doorway through which a dependency is reached. | A service hatch in a wall — you pass things through it. |
| `pct_today` | The percentage of a book's pages read today. | How far through the book you got before closing it. |
| Read-only | The module may look but never write. | A museum visitor who may look but must not touch. |
| Schema version | The number naming which version of the data contract a message speaks. | A form's edition number so both sides know the revision. |
| Socket contract | The agreed shape of what goes in and what comes back. | A plug and socket that only fit together one correct way. |
| View-model | The tidy, ready-to-render shape the screen needs. | The plated dish handed to the waiter, ready to serve. |
